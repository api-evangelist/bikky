# Bikky

> Bikky is a New York-based Customer Data Platform (CDP) built exclusively for large, multi-unit restaurant brands, serving thousands of locations for companies such as Bojangles, MOD Pizza, Dave's Hot Chicken, and Long John Silver's. It integrates with point-of-sale, online ordering, payment, loyalty, reservation and feedback systems to build a single source of truth on guests — cleaning, standardizing and de-duplicating data to reveal behavior, frequency, lifetime value and menu performance across channels.

## Agent notice

Bikky publishes **no public, self-service API**. There is no developer portal, no API reference, no OpenAPI or GraphQL contract, no MCP server, no A2A agent card, and no `/.well-known/` discovery documents on any Bikky host. `api.bikky.com` resolves to a live AWS load balancer that backs the customer console at `app.bikky.com`, but it answers HTTP 404 with an empty body on every path probed and is not documented for third-party use. Data access — API integrations, Snowflake data shares, SFTP, and CSV upload — is arranged directly with Bikky's sales and engineering team as part of a customer contract. An agent cannot self-serve credentials or call Bikky programmatically.

## Data exchange

Bikky's integration surface is inbound: it consumes partner APIs on a customer's behalf rather than exposing one.

- [Integrations](https://www.bikky.com/integrations): Push-button API integrations with ordering, POS, payments, loyalty, feedback, marketing and reservation providers. Real-time ingest for most POS and online ordering sources; nightly for reservations and loyalty.
- Snowflake data shares: direct, secure sharing for brands running their own Snowflake warehouse, with no copying or movement of data.
- SFTP: push and pull integrations for core data types.
- CSV upload: orders, guests, reservations and loyalty uploaded directly.

Named partner systems on the integrations page include Clover, Olo and Qu (ordering); Fiserv, FreedomPay and Heartland (payments); Punchh, Sparkfly and Thanx (loyalty); Ovation and Tattle (feedback); Braze, Attentive and Klaviyo (marketing); and OpenTable, Resy and Tock (reservations).

## Security and compliance

- [Trust Center](https://trust.bikky.com/): Vanta-hosted. Renders client-side; the certification list is not machine-readable anonymously.
- SOC 2 certified; system design and security policies stated as aligned with NIST best practices; customer data encrypted at rest; regular vulnerability scanning, penetration tests and policy reviews (source: https://www.bikky.com/).
- No published vulnerability disclosure channel: no `security.txt`, no responsible-disclosure page, no bug bounty program.
